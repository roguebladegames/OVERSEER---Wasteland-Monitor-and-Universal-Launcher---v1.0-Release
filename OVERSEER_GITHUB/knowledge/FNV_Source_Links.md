# FNV Overseer - Recommended Source Downloads

## How to Enhance the Knowledge Base
1. Download the files from the links below.
2. Place them in the `GRIM/OVERSEER/sources/` folder (create it if it doesn't exist).
3. Run the "Refresh Sources" button in the app (or the ingestion script).
4. The assistant will then have deeper, more accurate context for analyzing your load orders, logs, and conflicts.

## Core Recommended Sources

### 1. xNVSE (New Vegas Script Extender)
**Link:** https://github.com/xNVSE/NVSE  
**What to download:** The full repository (or at least the wiki and any documentation files).  
**Why:** Best reference for NVSE functions, scripting, and common pitfalls.

### 2. GECK Wiki
**Link:** https://geckwiki.com/  
**What to download:** Export or save pages from the Functions category and Records category.  
**Why:** Core engine record types and function reference.

### 3. xEdit / FNVEdit Documentation
**Link:** https://github.com/TES5Edit/TES5Edit  
**What to download:** The wiki and any manual files.  
**Why:** Essential for understanding dirty edits, cleaning mods, and creating patches.

### 4. Additional Helpful Resources
- Fallout New Vegas Fandom GECK Page: https://fallout.fandom.com/wiki/Fallout:_New_Vegas_GECK
- Community Modding Guides: Search Nexus Mods for “FNV xEdit cleaning” and “FNV load order best practices”

## Notes
- Always respect the original authors' copyrights — these links are for personal, local use only.
- After downloading, the ingestion script will convert them into the structured format the LLM can use effectively.
- This keeps Overseer completely free and accessible while giving users the deepest possible modding assistance.

This file is meant to be displayed directly in the app's Sources tab. Users can click the links to open them in their browser.
