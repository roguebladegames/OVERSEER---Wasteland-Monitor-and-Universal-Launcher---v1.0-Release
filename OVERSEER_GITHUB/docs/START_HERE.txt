RUN
---
  Double-click:  OVERSEER.exe
  Or:            Launch OVERSEER.bat

  A desktop window opens. Close the window to quit.


FIRST 60 SECONDS
----------------
  1. Theme: RobCo green or Pip-Boy amber
  2. Detect / scan for Fallout installs and plugins.txt
  3. (Optional) Start Ollama for full chat answers
  4. (Optional) Start RTSS if you want live FPS
  5. Launch your game from the toolbar when ready
