# OVERSEER - Wasteland Monitor and Universal Launcher - v1.0 Release
OVERSEER is a Fallout-themed control room for your PC. It launches ALL Fallout PC ports from one location, watches your CPU/RAM/GPU/FPS in real time, reads your load order and plugins, and gives you a local optional AI assistant that can provide game guidance, crash logs evaluation, and lore. YOU decide and provide the logic.

Everything provided is my source code. 
No external applications, .pyd, or .dll files.

To build from source, install the Python dependencies from `requirements.txt` and run `overseer.py'.
